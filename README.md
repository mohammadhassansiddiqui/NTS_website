# National Testing Service - Pakistan (NTS™) Portal Clone

An authentic, fully functional recreation of the official **National Testing Service - Pakistan** website (`https://www.nts.org.pk/`).

---

## 🌟 Included Features & Pages

1. **Top Bar & Navigation Header**
   - Official Helpline (UAN: `+92-51-844-444-1`), email (`query@nts.org.pk`), and working hours.
   - Links to 1Bill Payment Guide, FAQs, Downloads, and direct Candidate Portal (`portal.nts.org.pk`).
   - Authentic NTS crest, brand tagline, and navigation menus with multi-level dropdowns (About Us, Tests & Products, Open Applications, Roll No. Slips, All Results, Schedule, CSR, Contact Us).

2. **Breaking News / Ticker Bar**
   - Real-time animated ticker with pause-on-hover featuring latest announcements (Fee waiver for disabled candidates, GAT/NAT updates, 1Link 1Bill payment instructions).

3. **Hero Carousel**
   - High-impact rotating slides for NAT™ (Undergraduate Admissions), Federal & Provincial Recruitment Tests, and GAT™ (Graduate Assessment Test for MS/M.Phil/Ph.D).
   - Dynamic slide indicators and previous/next controls.

4. **Iconic 4 Quick Action Cards**
   - Direct access to **Open Applications**, **Roll No. Slips**, **All Results**, and **Candidate Portal**.

5. **Tabbed Examination Workspace**
   - **Open Applications**: Live searchable and filterable database of current active test projects (NAT, GAT General & Subject, FBR, WAPDA, OGDCL, SELD Sindh, SNGPL, PTA, USAID Scholarships).
   - **Roll Number Slips**: Enter CNIC (e.g. `61101-1234567-1`) to view and print official Roll No. Slip / Admit card with candidate details, center location, time, barcode, and test instructions.
   - **All Results**: Enter CNIC or Roll Number to inspect official Electronic Result Card with section-wise breakdown, total score, percentile, and print button.
   - **Test Schedule**: Annual calendar for NAT™ and GAT™ examination series.

6. **Products & Services Showcase**
   - Comprehensive test patterns and syllabi for NAT, GAT-General, GAT-Subject, Recruitment Screening Tests, International Tests (TOEFL, TOEIC), and CSR initiatives.

7. **1Bill / 1Link Payment Guide**
   - Step-by-step instructions for paying fees via Mobile Banking Apps, EasyPaisa, JazzCash, ATMs, and bank counters.

8. **CSR & Special Persons Policy**
   - 100% fee waiver guidelines, accessible centers, and scribe accommodations for persons with disabilities.

9. **Candidate Portal Modal (portal.nts.org.pk)**
   - Interactive Sign In and Registration forms.

10. **Head Office & Regional Help Centers**
    - Head Office (Islamabad) coordinates and regional help centers (Lahore, Karachi, Peshawar, Quetta).

---

## 🚀 How to Run the Website

Simply open `index.html` in any modern web browser:
- Double-click `index.html` in file explorer, or
- Right click `index.html` -> Open with Google Chrome / Microsoft Edge.

## 📱 Responsive Update

The site now adapts to phones (Android / iPhone), tablets (iPad), laptops, desktops and widescreens.

- `css/responsive.css` – responsive layer (hamburger menu, card-style tables, wrapped pills, form fixes, widescreen scaling). Loaded last on every page.
- `js/responsive.js` – mobile menu toggle, table labels for card layout, tap-again-to-close tabs, tap-selected-pill-to-go-home, hero swipe.
- Same stack as before: plain HTML, CSS and vanilla JavaScript. No build step, open `index.html` to run.
